Penerbitan Otomatis Let's Encrypt

Sertifikat valid 90 hari, gratis, dan otomatis diperbarui sebelum masa berlaku habis.

Persyaratan Sebelum Menerbitkan:
  • DNS record domain (dan subdomain aliases) sudah terarah ke IP server ini.
  • Port 80 (HTTP) dan Port 443 (HTTPS) tidak diblokir oleh firewall hosting / ISP.
  • Web server dapat merespons ACME challenge HTTP-01 pada /.well-known/acme-challenge/.
